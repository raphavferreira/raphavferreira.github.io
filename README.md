# Portfólio profissional — Raphael Ferreira

Site profissional de Engenharia Elétrica, com foco em Sistemas Elétricos de Potência, Subestações, Estudos Elétricos e SPCS.

## Publicação

Este projeto foi preparado para publicação direta no GitHub Pages.

1. Envie todos os arquivos para a raiz do repositório `raphavferreira.github.io`.
2. Mantenha o GitHub Pages configurado para a branch `main` e a pasta `/(root)`.
3. Após o envio, o site será atualizado automaticamente.

## Estrutura

- `index.html`: conteúdo e estrutura da página;
- `styles.css`: identidade visual e responsividade;
- `script.js`: menu para dispositivos móveis e pequenos comportamentos;
- `favicon.svg`: ícone do site exibido na aba do navegador;
- `.nojekyll`: impede processamento desnecessário pelo Jekyll.

## Privacidade

O portfólio utiliza apenas descrições profissionais não confidenciais. Não publique desenhos, documentos ou dados proprietários de clientes e empresas.
